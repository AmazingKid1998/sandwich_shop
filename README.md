# Sandwich Shop (Flutter)

A simple Flutter app that allows users to order sandwiches. The project supports running on Web, Android emulator/device, and other Flutter-supported platforms.

This repository contains:
- The application source code (under `lib/`)
- Unit/widget tests (under `test/`)
- Integration (end-to-end) tests (under `integration_test/`)

---

## Prerequisites

Ensure the following are installed and working:

- **Flutter SDK** (and Dart, included with Flutter)
- **Git**
- **Android Studio + Android SDK** (for Android emulator/device testing) and/or a physical device
- (Optional) **VS Code** with the Flutter + Dart extensions

Verify Flutter setup:
```bash
flutter doctor
